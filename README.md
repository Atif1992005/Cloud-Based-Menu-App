## 🌟 About the Project

**Cloud-Based Menu App (Food Book)** is a web-based restaurant menu and billing system developed as part of our **Cloud Computing** subject.

The application provides a digital platform where users can explore restaurant menus and interact with the available services. It aims to simplify restaurant operations through a user-friendly interface, online accessibility, database management, and integrated authentication.

The project demonstrates how web technologies and cloud-based hosting can be combined to develop an accessible restaurant application.

## 🎯 Project Objectives

- Develop a digital platform for restaurant menu management.
- Provide users with convenient online menu access.
- Implement user authentication and login functionality.
- Store and manage restaurant-related information using a database.
- Integrate online payment functionality in test mode.
- Demonstrate cloud-based application deployment and accessibility.

## ☁️ Cloud Computing Concepts

This project demonstrates the practical application of cloud computing concepts:

- **Cloud Hosting:** The web application is deployed on an online hosting platform, making it accessible over the internet.
- **Online Accessibility:** Users can access the application without depending exclusively on a local development environment.
- **Cloud-Based Authentication:** Firebase Authentication provides supported user login functionality.
- **Database Management:** MySQL is used to store and manage application information.
- **Third-Party Service Integration:** External services are integrated to support authentication and payment functionality.

## ⚙️ Application Workflow

1. The user opens the Cloud-Based Menu App.
2. The user logs in or continues using guest access.
3. The application provides access to restaurant information and digital menus.
4. The user interacts with the available application features.
5. Relevant information is processed and managed through the backend and database.
6. Payment functionality can be explored using Razorpay test mode.

## 🖥️ Project Structure

The project is organized around the following main components:

- **Frontend:** User interface and application interaction.
- **Backend:** Server-side processing using PHP.
- **Database:** MySQL database for storing application information.
- **Authentication:** Firebase Authentication.
- **Payment Integration:** Razorpay test environment.
- **Deployment:** Online web hosting.

## 🚀 Getting Started

To run the project locally:

### Prerequisites

- XAMPP
- PHP
- MySQL
- Web browser
- Firebase project configuration

### Installation

1. Clone or download this repository.

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Move the project folder into the XAMPP `htdocs` directory.

3. Start Apache and MySQL from the XAMPP Control Panel.

4. Import the project's database into phpMyAdmin, if a database export is provided.

5. Configure the database connection details in the project configuration file.

6. Configure the Firebase authentication settings.

7. Open the application in your browser:

   ```text
   http://localhost/your-project-folder/
   ```

*Note: Update the configuration according to the actual files and database structure in the repository.*
